# 🚀 Design and Analysis of Algorithms (DAA)

Welcome to the **Design and Analysis of Algorithms (DAA)** practical repository! This repository contains Python implementations of various fundamental algorithms, demonstrating their logic, time complexities, and space complexities.

## 📌 Table of Contents

The `List of Experiments` folder includes the following practical implementations:

| No. | Experiment Name | Topic |
|:---:|:---|:---|
| 1 | **[Practical 1](List%20of%20Experiments/Practical%201.py)** | Sorting Algorithms (Bubble Sort, etc.) |
| 2 | **[Practical 2](List%20of%20Experiments/Practical%202.py)** | Searching Algorithms (Linear Search, Binary Search) |
| 3 | **[Practical 3](List%20of%20Experiments/Practical%203.py)** | Heap Sort (Max Heap) |
| 4 | **[Practical 4](List%20of%20Experiments/Practical%204.py)** | Factorial (Iterative & Recursive Approaches) |
| 5 | **[Practical 5](List%20of%20Experiments/Practical%205.py)** | 0/1 Knapsack Problem (Dynamic Programming) |
| 6 | **[Practical 6](List%20of%20Experiments/Practical%206.py)** | Matrix Chain Multiplication (Dynamic Programming) |

---

## 💻 Tech Stack
- **Language**: Python 3.x
- **Concepts Covered**: Sorting, Searching, Recursion, Dynamic Programming, Heap Data Structure

---

## ⚙️ How to Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Harsh-Katarmal/Design-And-Analysis-of-Algorithm-.git
   ```
2. **Navigate to the directory**:
   ```bash
   cd "Design-And-Analysis-of-Algorithm-"
   ```
3. **Run any experiment** using Python:
   ```bash
   python "List of Experiments/Practical 1.py"
   ```

---

## 📝 Learning Outcomes
By exploring these practicals, you'll gain an understanding of:
- How to measure and analyze the performance of algorithms.
- Choosing the right algorithm based on time (`O(n)`, `O(n log n)`, `O(n^2)`) and space complexity.
- Problem-solving techniques like **Divide and Conquer** and **Dynamic Programming**.
